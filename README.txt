LAS ROSAS HOTEL & SPA — SITIO WEB ESTÁTICO

Cómo verlo en tu computadora:
1. Descomprime el archivo ZIP.
2. Abre la carpeta "las-rosas-spa".
3. Haz doble clic en "index.html".

No necesita instalar Python, Flask ni una base de datos.

Para publicarlo en Render:
1. Sube la carpeta a un repositorio de GitHub.
2. En Render selecciona "New" > "Static Site".
3. Conecta el repositorio.
4. Build Command: déjalo vacío.
5. Publish Directory: .
6. Publica.

Notas:
- El sitio cambia entre español e inglés con el botón EN/ES.
- Las fotos del encabezado cambian automáticamente.
- Los servicios se abren por categorías.
- Los botones de contacto abren WhatsApp.
- Revisa y confirma precios, descripciones, horario y domicilio antes de publicar.

Actualización:
- La galería incluye flechas para avanzar y retroceder, además de navegación con las teclas izquierda/derecha.
- Se agregó información de llegada, traje de baño y política de cancelación en español e inglés.
